# Containers

A container holds other widgets. It gives you a new `Ui` in a closure, and whatever you add there ends up inside it. Here a group draws a box around a label and a button:

<Example name="container_frame" item="ui.group" />

Containers decide where their content goes (a sidebar, a floating window, a scrollable box) and often draw something around it.
