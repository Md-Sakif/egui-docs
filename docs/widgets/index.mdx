# Widgets

A widget is one piece of UI: a button, a slider, a line of text. You add widgets to a `Ui`, and each one returns a [`Response`](../concepts/responses.mdx) that tells you what the user did with it.

There are two ways to add most widgets:

- **A shortcut method** on `Ui` for the common case: `ui.button("Save")`, `ui.checkbox(&mut on, "Enabled")`.
- **The widget type itself**, with `ui.add(...)`, when you want more options: `ui.add(egui::Button::new("Save").fill(color))`.

Every page in this section shows a complete program you can run.
