# Companion crates

egui keeps its core small. A lively ecosystem of crates adds the bigger pieces. This page is a map of the ones people reach for most.

:::warning Not covered by these docs' tests
Unlike the rest of this site, the crates on this page are **not** exercised by the example tests, apart from the image loading in `egui_extras`. Use each crate's own documentation for code, and treat this page as a list of names to look up.
:::

:::tip Match the versions
Every one of these crates is built for a specific version of egui, and egui releases often include breaking changes. Before adding a crate, check that it has a release for the egui version you use. A mismatch shows up as confusing errors such as "expected `egui::Ui`, found `egui::Ui`".
:::

## From the egui project

| Crate | What it adds |
|---|---|
| [`eframe`](https://crates.io/crates/eframe) | The framework these docs use to run egui on desktop and web |
| [`egui_extras`](https://crates.io/crates/egui_extras) | Image loaders (used on the [Image](./widgets/image.mdx) page), `TableBuilder` for big tables, a date picker, syntax highlighting |
| [`egui_plot`](https://crates.io/crates/egui_plot) | 2D plots: lines, bars, points, with pan and zoom |
| [`egui_kittest`](https://crates.io/crates/egui_kittest) | UI testing and screenshots. It is what [tests these docs](./how-these-docs-are-tested.mdx) |

## Other ways to run egui

eframe is the usual way to run an egui app, but egui itself only needs something to feed it input and draw its output. That is why it also runs inside game engines:

| Crate | What it adds |
|---|---|
| [`bevy_egui`](https://crates.io/crates/bevy_egui) | egui inside the Bevy game engine |
| [`egui-wgpu`](https://crates.io/crates/egui-wgpu), [`egui-winit`](https://crates.io/crates/egui-winit), [`egui_glow`](https://crates.io/crates/egui_glow) | The building blocks eframe is made of, for wiring egui into your own renderer |
