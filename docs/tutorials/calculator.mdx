# Tutorial: a calculator

In this tutorial you build a working calculator in three steps: first the layout, then the logic, then some color. Along the way you meet the pieces you will use in every egui app: state, layouts, buttons and styling.

### The keys are data

<Example name="calc_1_layout" item="const KEYS" />

Instead of writing twenty lines that each add a button, the keys are a table: five rows of four labels. The UI code loops over it. When the UI is built from data like this, changing the layout later is a matter of editing the table.

### The display

<Example name="calc_1_layout" item="ui.with_layout" />

`with_layout` changes how widgets are arranged inside its closure. `top_down(Align::RIGHT)` still stacks widgets from top to bottom, but lines them up against the right edge, which is where a calculator shows its number.

`RichText` is how you style a piece of text. Here it makes the number 36 points tall. See [RichText](../widgets/rich-text.mdx).

### The keypad

<Example name="calc_1_layout" item="egui::Grid::new" />

A [`Grid`](../containers/grid.mdx) puts widgets in rows and columns. Each widget you add goes into the next cell, and `ui.end_row()` starts a new row.

`ui.add_sized` adds a widget with an exact size, so all keys are 56 by 44 points no matter how wide their label is.

Run it. You have a calculator that looks right and does nothing.

## What you learned

- App state is a struct, and the logic is ordinary methods on it.
- [`Grid`](../containers/grid.mdx) arranges widgets in rows and columns, and `add_sized` gives them a fixed size.
- `with_layout` controls alignment. More in [Layout](../concepts/layout.mdx).
- [`Button`](../widgets/button.mdx) and [`RichText`](../widgets/rich-text.mdx) have builder methods for color, size and shape.

## Ideas to take it further

- Let people type on the keyboard. The [Input](../concepts/input.mdx) page shows how to read key presses.
- Add a history of past results in a [ScrollArea](../containers/scroll-area.mdx).
- Publish it: see [Publishing for desktop](../publishing/desktop.mdx).
